# Project: Interrupt-driven CAN Bus telemetry with connectors integrity validation with USART & Motor Speed Measurement using optical sensor

An industrial bare-metal C (CMSIS) firmware developed for the **STM32F446RE** ARM Cortex-M4 microcontroller. The system performs high-precision motor speed acquisition via an **HW-006 optical sensor**, streams real-time telemetry across **USART2** and an industrial **CAN Bus**, executes multi-pin connector integrity diagnostics, and feeds a **Siemens S7-300 PLC** system for automated safety monitoring and HMI visualization.

---

## 1. Project Overview & STM32 Bare-Metal Core

The primary core of this embedded node runs on an **STM32F446RE** microcontroller operating without HAL/Cube libraries (direct register access) to ensure deterministic execution, minimal memory footprint, and low-latency interrupt handling:

* **Optical Speed Sensing (`EXTI0`):** Captures high-speed pulses generated by an HW-006 optical sensor on pin `PB0` using direct edge-triggered hardware interrupts (`EXTI0`).
* **Timer Base & Dual Telemetry (`TIM2`):** Configures `TIM2` for a precise 1-second timebase to calculate motor speed ($\text{RPM} = \frac{\text{pulses} \times 60}{\text{slots}}$), transmit serial diagnostic strings over **USART2 (PA2/PA3)**, and broadcast raw 16-bit speed words over **CAN1 (PA11/PA12)**.
* **PLC Hardware Synchronization (`PB9`):** Generates a non-blocking 1 Hz square wave on GPIO pin `PB9` via atomic register toggles (`ODR`), providing a hardware timebase pulse for the PLC.
* **Connector Integrity Test (`EXTI15_10`):** Implements a dedicated pin-level continuity check triggered by the user button on `PC13`. Toggles diagnostic outputs `PB1–PB4` and evaluates inputs `PB5–PB8` using internal pull-down resistors to detect open or swapped harness lines.
* **Industrial PLC Interface:** Interfaces with a **Siemens S7-300 PLC** running GRAFCET control logic. The PLC captures CAN telemetry mapped to `%IW800` (transferred to `%DB2.DBW0` for HMI display) and uses a `CTU` counter on digital input `%I0.3` to execute an automated motor safety shutdown after 14,400 seconds (4 hours).

---

## 2. Key Technical Features (STM32 Architecture)

* **Zero-HAL Bare-Metal Firmware:** Written entirely in C using direct CMSIS register access for maximum execution speed and zero overhead.
* **NVIC Priority Hierarchy:** Structured interrupt handling where diagnostic tests (`EXTI15_10`, Priority 0) take precedence over motor pulse capture (`EXTI0`, Priority 1) and periodic reporting (`TIM2`, Priority 2).
* **Normal Mode CAN Bus Peripheral:** Operates `CAN1` in normal mode (`CAN1->BTR &= ~(CAN_BTR_SILM | CAN_BTR_LBKM)`), routing data through an SN65HVD230 transceiver to an industrial PROFINET/CAN Gateway.
* **Non-Blocking Signal Generation:** Generates a clean $500\text{ ms}$ HIGH / $500\text{ ms}$ LOW signal on `PB9` without CPU `delay()` loops, avoiding ISR starvation and complying with PLC input filtering time constants.
* **Atomic Bit Manipulation (`BSRR`):** Drives harness test outputs via the Bit Set/Reset Register (`BSRR`) to eliminate read-modify-write race conditions.
* **Hardware Pull Resistors:** Configured internal Pull-Downs on `PB5–PB8` and Pull-Up on `PB0` to guarantee stable 0V logic levels and eliminate floating-wire noise.

## 3. Hardware Connections & STM32 Pin Mapping

| STM32F446RE Pin | Connected Peripheral / Device | Peripheral Mode / Signal Description |
| :--- | :--- | :--- |
| **PB0** | HW-006 Optical Sensor Out | Digital Input (`EXTI0` with Internal Pull-Up) |
| **PC13** | Onboard User Button | Diagnostic Trigger (`EXTI15_10` Falling Edge) |
| **PA5** | Onboard Status LED | Pulse Detection Visual Indicator (Toggle) |
| **PB1 – PB4** | Test Harness Pins (Out) | Diagnostic Pulse Outputs (`BSRR` Driven) |
| **PB5 – PB8** | Test Harness Pins (In) | Diagnostic Sense Inputs (Internal Pull-Downs) |
| **PA2 / PA3** | ST-LINK VCP (USB Port) | Virtual COM Port Serial Telemetry via USART2 |
| **PA11 / PA12** | SN65HVD230 Transceiver (`CRX`/`CTX`) | `CAN1` Alternate Function 9 (AF9) Transmission |
| **PB9** | Siemens PLC Input Module (`%I0.3`) | 1 Hz Square-Wave Timebase Pulse (1s Toggle) |
