# Project: CAN Bus telemetry with connectors integrity validation with USART & Motor Speed Measurement using optical sensor

An industrial bare-metal C (CMSIS) firmware developed for the **STM32F446RE** microcontroller to monitor motor rotation speed via an **HW-006 optical sensor**, transmit speed telemetry over a **CAN Bus**, validate connector wiring integrity, and interface with a **Siemens S7-300 PLC** system for automated safety shutdown and HMI monitoring.

---

## 1. Project Overview

In automated manufacturing lines and motor test benches, continuously monitoring rotational speed (RPM), broadcasting telemetry over an industrial CAN bus, and enforcing structured safety limits are essential to prevent mechanical downtime. 

This project implements a deterministic, multi-interrupt embedded monitoring node paired with a Siemens S7-300 PLC control environment that:
* **Optical Speed Sensing:** Counts pulses generated by an HW-006 optical sensor on `PB0` using high-priority hardware interrupts (`EXTI0`).
* **Deterministic Telemetry & Pulse Output:** Uses `TIM2` configured for a 1-second timebase to calculate motor speed ($\text{RPM} = \frac{\text{pulses} \times 60}{\text{slots}}$), transmit serial telemetry over **USART2 (ST-LINK VCP)**, broadcast 16-bit speed words over **CAN1**, and toggle `PB9` as a 1 Hz square-wave clock pulse for the PLC.
* **Industrial PLC Integration & Auto-Shutdown:** Interfaces with a **Siemens S7-300 PLC** running GRAFCET control (managing motor contactors, Green Run LED, and Red Fault LED). The PLC maps incoming CAN telemetry to `%IW800` (moved to `%DB2.DBW0` for HMI visualization) and uses a `CTU` counter on `%I0.3` to execute an automated motor shutdown after 14,400 seconds (4 hours) of operation.
* **Connector Integrity Test:** Triggers an immediate multi-pin continuity check upon pressing the User Button on `PC13` (`EXTI15_10`), toggling `PB1–PB4` outputs and evaluating `PB5–PB8` inputs to detect cut or swapped wires.

---

## 2. Key Technical Features

* **Zero-HAL Bare-Metal Firmware:** Written entirely in C using direct CMSIS register access for low memory overhead and maximum execution speed.
* **NVIC Priority Hierarchy:** Structured interrupt handling where diagnostic tests (`EXTI15_10`, Priority 0) take precedence over motor pulse capture (`EXTI0`, Priority 1) and periodic reporting (`TIM2`, Priority 2).
* **Normal Mode CAN Bus Communication:** Replaces loopback mode with standard transceiver operations to transmit CAN frames to an industrial PROFINET/CAN Gateway mapped directly to PLC memory (`%IW800`).
* **Non-Blocking PLC Clock Generation:** Generates a clean $500\text{ ms}$ HIGH / $500\text{ ms}$ LOW square wave on `PB9` via atomic XOR bit toggling (`ODR`), avoiding CPU delay locks and matching PLC input optocoupler filtering times.
* **Atomic Bit Manipulation (`BSRR`):** Pin toggling during connector diagnostics uses the Bit Set/Reset Register (`BSRR`) to eliminate race conditions and keep signal changes atomic.
* **Hardware Debounce & Pull Resistors:** Configured internal Pull-Downs on `PB5–PB8` and Pull-Up on `PB0` to guarantee stable 0V logic levels and eliminate parasitic floating-wire reads.

## Mathematical Formulas

### 1. Speed Calculation
$$\text{Speed (RPM)} = \frac{\text{Pulse Count} \times 60}{\text{ENCODER\_SLOTS}}$$

Where:
* **Pulse Count:** Number of pulses detected by the HW-006 sensor in 1 second.
* **ENCODER_SLOTS:** Number of physical slots on the encoder wheel.

### 2. Baud Rate Register (BRR) for USART2 @ 16 MHz (115200 Bps)
$$\text{USARTDIV} = \frac{16\,000\,000}{16 \times 115200} = 8.68055$$
$$\text{DIV\_Mantissa} = 8 = \text{0x8}, \quad \text{DIV\_Fraction} = \text{round}(16 \times 0.68055) = 11 = \text{0xB}$$
$$\text{BRR} = (0\text{x}8 \ll 4) \mid 0\text{xB} = \mathbf{0\text{x}8\text{B}}$$
